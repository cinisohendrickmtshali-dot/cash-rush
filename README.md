# 💰 Cash Rush — South African Business Simulator

A mobile-first business simulation game built for South African players.

## 🎮 The Concept

Start with **R500** and build a profitable small business.

Buy stock → Set prices → Serve customers → Track profit → Reinvest → Grow.

Learn real business concepts through gameplay.

## 📱 Play It

Open `index.html` in any modern browser, or visit the GitHub Pages link.
